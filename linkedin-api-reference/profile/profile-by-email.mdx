## Find the LinkedIn profile behind a work email

Give a work email address and get the LinkedIn profile of the person who uses it (reverse email lookup).

<CodeGroup>

```javascript JavaScript
const params = new URLSearchParams({
  email: 'john.smith@acme.com',
});
fetch(`https://api.harvestapi.io/linkedin/profile-by-email?${params.toString()}`, {
  headers: { 'X-API-Key': '<api-key>' },
})
  .then((response) => response.json())
  .then((data) => console.log(data));
```

```bash cURL
curl --request GET \
  --url 'https://api.harvestapi.io/linkedin/profile-by-email?email=john.smith%40acme.com' \
  --header 'X-API-Key: <api-key>'
```

```python Python
import requests

url = "https://api.harvestapi.io/linkedin/profile-by-email"

params = {"email": "john.smith@acme.com"}

headers = {"X-API-Key": "<api-key>"}

response = requests.request("GET", url, headers=headers, params=params)

print(response.text)
```
