## Get in-depth insights about a LinkedIn company

- **Company profile**: description, industry, type, headquarters address, specialties, estimated revenue range and headcount.
- **LinkedIn's AI-generated summaries**: how the company makes money with its latest yearly and quarterly revenue, strategic priorities, business challenges and the competitive landscape, each with its sources.
- **People**: key executives, their recent LinkedIn posts, and suggested people to reach out to with the reasons why (recently hired, posted on LinkedIn, etc.).
- **Growth charts**: headcount over the last two years, headcount by job function, new hires, and job openings by function.
- **Alerts**: the latest company posts, employee job changes and growth signals, plus similar companies that people also viewed.

The LinkedIn AI-generated summaries exist mostly for larger companies. For other companies `howTheyMakeMoney`, `competitiveLandscape` and `executiveVoices` are `null`, and `strategicPriorities`, `businessChallenges`, `keyPeople` and `relatedNews` are empty.

```javascript JavaScript
const params = new URLSearchParams({
  query: 'https://www.linkedin.com/company/google/', // by URL
  // query: 'google', // by universal name alternatively
  // query: '1441', // or by company ID
});

fetch(`https://api.harvestapi.io/linkedin/account-insights?${params.toString()}`, {
  headers: { 'X-API-Key': '<api-key>' },
})
  .then((response) => response.json())
  .then((data) => console.log(data));
```

```bash cURL
curl --request GET \
  --url https://api.harvestapi.io/linkedin/account-insights?query=google \
  --header 'X-API-Key: <api-key>'
```

```python Python
import requests

url = "https://api.harvestapi.io/linkedin/account-insights?query=google"

headers = {"X-API-Key": "<api-key>"}

response = requests.request("GET", url, headers=headers)

print(response.text)
```
