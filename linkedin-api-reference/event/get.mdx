---
title: 'Get Event'
openapi: 'GET /linkedin/event'
---

Get a LinkedIn event by its URL or ID: its description, exact start and end, place, organizer, speakers and the post
that announces it. Event URLs carry either the event's ID or its vanity name, and both work.

<CodeGroup>

```javascript JavaScript
const params = new URLSearchParams({
  url: 'https://www.linkedin.com/events/7523060148135907328/', // by URL
  // eventId: '7523060148135907328', // by event ID alternatively
});

fetch(`https://api.harvestapi.io/linkedin/event?${params.toString()}`, {
  headers: { 'X-API-Key': '<api-key>' },
})
  .then((response) => response.json())
  .then((data) => console.log(data));
```

```bash cURL
curl --request GET \
  --url 'https://api.harvestapi.io/linkedin/event?eventId=7523060148135907328' \
  --header 'X-API-Key: <api-key>'
```

```python Python
import requests

url = "https://api.harvestapi.io/linkedin/event?eventId=7523060148135907328"

headers = {"X-API-Key": "<api-key>"}

response = requests.request("GET", url, headers=headers)

print(response.text)
```
