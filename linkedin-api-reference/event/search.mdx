---
title: 'Search Events'
openapi: 'GET /linkedin/event-search'
---

Search LinkedIn events by keywords. Each page holds 50 events, sometimes a few more. LinkedIn lets a search be
paged only so far: `pagination.totalElements` may count more events than the pages reach, and a page past the last
event comes back empty. Use [Get event](/linkedin-api-reference/event/get) for an event's full details and exact time.

<CodeGroup>

```javascript JavaScript
const params = new URLSearchParams({
  search: 'marketing',
  page: '1',
});
fetch(`https://api.harvestapi.io/linkedin/event-search?${params.toString()}`, {
  headers: { 'X-API-Key': '<api-key>' },
})
  .then((response) => response.json())
  .then((data) => console.log(data));
```

```bash cURL
curl --request GET \
  --url 'https://api.harvestapi.io/linkedin/event-search?search=marketing&page=1' \
  --header 'X-API-Key: <api-key>'
```

```python Python
import requests

url = "https://api.harvestapi.io/linkedin/event-search?search=marketing&page=1"

headers = {"X-API-Key": "<api-key>"}

response = requests.request("GET", url, headers=headers)

print(response.text)
```
